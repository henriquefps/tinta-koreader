Tinta: protótipo do dashboard

Plugin do KOReader que transforma o Kindle num painel de apps. A tela está em tamanho real do Kindle KT3 (600 × 800 px, preto e branco), com as apps que o sistema público traz: Notificações, Sistema, Bateria, Relógio, Repouso, Timer, Nota e Contagem. Os dados são de exemplo.

Como usar

  • Toque nos widgets, no sino, no relógio ou na barra de baixo, como no aparelho.
  • Menu › Apps abre o lançador; Menu › Organizar o início abre o organizador.
  • Parâmetros de URL: ?view=home|central|apps|sleep|sistema|sleepcfg|organizar|relogio|timer|nota|contagem|bateria, &land=1, &style=analogico e &shot=1 (só a tela, em px reais, para as capturas).
  • O horário é fixo (sexta, 16 de outubro, 14:32) para as capturas serem reproduzíveis.
